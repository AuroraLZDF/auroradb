# 发版冒烟清单（Linux / Windows）

每次发版前在 Linux 与 Windows 上各按本清单跑一遍，结果回填到「结果」列。
同一版本只跑一次；发布补丁版本时至少覆盖第 1、2、3、4、8 节。

| --- | --- |
| 版本号 | |
| 产物 | Linux：`.deb` / AppImage lite / AppImage full / `.rpm`；Windows：NSIS `.exe` |
| 测试机 | 发行版与版本 / Windows 版本（Win10 与 Win11 各一台更佳） |
| 测试人 / 日期 | |
| 数据库环境 | MySQL 版本、PostgreSQL 版本、SSH 隧道主机、TLS 是否启用 |

结果填写约定：`P` 通过、`F` 失败（需附现象与日志）、`N/A` 不适用。

## 10. 失败处理

- 记录失败项编号、复现步骤、截图与日志路径（Linux：`~/.local/share/mysql-client/logs/`；Windows：`%APPDATA%\mysql-client\logs\`）。
- 阻塞发版的失败项：安装/启动失败、连接不可用、查询结果错误、数据编辑或导入导出丢数据、激活失败。
- 非阻塞项记入下个版本的修复清单，并在发布说明中注明。
